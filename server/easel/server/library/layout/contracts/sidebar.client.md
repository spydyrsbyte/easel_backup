# easel.layout.sidebar@1

Icon-tabbed side panel. Each tab shows the attached child whose component id it names.

| Property | Type | Default |
|---|---|---|
| `disabled` | Boolean | `false` |
| `tabs` | Array | `[]` |
| `active` | String | `""` |

## Events

| Event | Payload |
|---|---|
| `select` | `id` String |
