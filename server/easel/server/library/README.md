# Easel Kit libraries

28 libraries expose 202 independent members: 85 Sobek server interfaces and 117 browser components. See [catalog.json](catalog.json) for library paths and each library's README, inventory and contracts.

Kits have no startup behavior. Every implementation is a default-exported class selected through a versioned interface. They declare no records, register no automations and install no security policies. Module/application consumers own rules, authoritative membership, viewer projection and persistence. Pure tools return replacement values without changing inputs; commit multi-container transfers together in the caller's transaction.

```js
const decks = Easel.Interfaces.create("easel.cards.deck@1");
const next = decks.draw(["a", "b", "c"], 2);
```

```js
await Easel.Interfaces.load("easel.cards.hand@1");
const hand = Easel.Components.create("easel.cards.hand@1", {props: {items: projectedCards}});
hand.on("select", ({id}) => selectCard(id));
```

Browser names also use explicit interface versions. Server and browser registries are independent. Local imports only load small shared validation/DOM helpers; they do not load the other member classes.

`Easel.Random.integer(min,max)` is the approved Go cryptographic source with inclusive min and exclusive max; `fraction()` returns a value in [0,1). Kits do not create random services or schedulers.

Run `node --test scripts/test-kits.mjs`, `go test ./internal/session -run Kit`, and the browser integration through `scripts/test-security.ps1`.

Shared internal value helpers have canonical sources in `game/`, and shared browser helpers in `client/`. Run `node scripts/sync-kit-support.mjs` after changing them. The copies inside each Kit keep all runtime imports package-local. Member implementation files remain separate and are not generated by this synchronization.

The deterministic server tools are value transformations, not persistence adapters. Their contracts state the accepted v1 policies; consumers decide authorization, record partitioning and transaction boundaries.
