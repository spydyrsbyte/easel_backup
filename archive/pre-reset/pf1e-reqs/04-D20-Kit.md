# 04 — D20 / WotC-Derivative Non-Core Kit (`easel.d20.kit`)

## 1. Overview & Scope
This section covers **Concern 2**: the standalone, non-core **`easel.d20.kit`** (`type: "kit"`, owner `easel`, host `d20`, name `kit`).

### Why This Is a Separate Non-Core Kit
Everything in `easel.d20.kit` represents mechanics shared across the D&D / d20 family of games (OD&D, AD&D, D&D 3.0/3.5e, Pathfinder 1e, Pathfinder 2e, D&D 5e, Starfinder, 13th Age, OSR) that do **not** belong in generic Core RP Kits (such as GURPS, Blades in the Dark, or Call of Cthulhu) and are **broader** than Pathfinder 1e alone:
- The classic 6 ability scores (`str`, `dex`, `con`, `int`, `wis`, `cha`) and `floor((score - 10) / 2)` modifier formula
- d20 roll checks (`1d20 + modifiers vs DC`), natural 1 / natural 20 automatic outcomes, critical threat range & critical confirmation rolls
- Armor Class breakdown (`Base 10 + Armor + Shield + Dex + Size + Natural + Deflection + Dodge`) & Saving Throws (`Fortitude`, `Reflex`, `Will` or 6-save variants)
- Hit Points (`current`, `max`, `temp`, `nonlethal`), Hit Dice, and consciousness / death threshold state transitions
- Vancian / Semi-Vancian / Spontaneous / Points-based Spellbooks (Levels 0–9, domain/school slots, concentration checks, caster level checks)
- Creature Size categories (Fine through Colossal) and space/reach tables
- Damage reduction (`DR X/material`), energy resistances/immunities/vulnerabilities, and 5-ft step / 5-10-5 diagonal movement
- Multi-denomination coinage (`pp`, `gp`, `sp`, `cp`) and coin weight

Because `easel.d20.kit` is a **Kit** (`type: "kit"`), every calculation brick and UI widget is registered in its `manifest.json` `interfaces` list and loaded strictly on-demand via `context.load("easel.d20.<member>@1")` or `application.load("easel.d20.<member>@1")`. It contains **zero** `data` schemas, **zero** `layers`, **zero** `automations`, and **zero** `security` rules.

## 4. How to Build Each Piece

### 4.1 `easel.d20.abilities@1` (`server/abilities.mjs`)
- Export `ABILITY_KEYS = ["str", "dex", "con", "int", "wis", "cha"]`.
- `abilityModifier(score)`: returns `Math.floor((score - 10) / 2)` (or `0` if `score === null || score === undefined` for mindless/undead/construct non-abilities).
- `resolveAbility(raw)`:
  - Input: `{ base, modifiers, damage = 0, drain = 0, penalty = 0, maxCap = null }`, plus `stacking` service from `easel.effects.stacking@1`.
  - Computes `total = Math.max(0, base + stackedBonus - drain)`.
  - Computes `baseMod = abilityModifier(total)`.
  - Applies ability damage and ability penalty (`-Math.floor((damage + penalty) / 2)` in 3.5e/PF1e mode, or configurable direct score reduction).
  - Applies `maxCap` (such as armor `maxDexBonus` or encumbrance `maxDex`) when requested.
  - Returns `{ base, total, modifier, damage, drain, penalty, breakdown }`.
- `pointBuyCost(scores, costTable)`: evaluates point-buy cost against a configurable cost map (defaulting to PF1e/3.5e costs).

### 4.2 `easel.d20.check@1` (`server/check.mjs`)
- Loads `easel.dice.roller@1` via `context.load("easel.dice.roller@1")`.
- `rollCheck({ mode = "normal", take = null, modifiers = [], dc = null, autoFailOn = 1, autoSuccessOn = 20 })`:
  - Uses `roller` for `1d20` (`normal`), `2d20kh1` (`advantage` / roll twice take higher), or `2d20kl1` (`disadvantage` / roll twice take lower), or deterministic `10`/`20` when `take === 10` or `take === 20`.
  - Computes total and returns `{ naturalRoll, dice, modifierTotal, breakdown, total, dc, isNatural1, isNatural20, success }`.
- `rollAttack({ attackModifiers, critRange = 20, critMultiplier = 2, confirmModifiers = [], targetAC = null, targetFlatFootedAC = null, concealmentMissChance = 0, fortificationChance = 0 })`:
  - Rolls the primary attack via `rollCheck`.
  - Evaluates whether `naturalRoll >= critRange` threatens a critical hit.
  - If threatened (and hits `targetAC` when known, or always rolls confirmation so the card has the result ready), rolls a second `1d20` confirmation check with `attackModifiers + confirmModifiers`.
  - Optionally rolls `1d100` for concealment miss chance and `1d100` for target fortification.
  - Returns a structured attack roll payload ready for `easel.d20.attackcard@1`.

### 4.3 `easel.d20.defense@1` (`server/defense.mjs`)
- `resolveArmorClass({ base = 10, modifiers = [], policyMap, maxDex = null, loseDexToAC = false })`:
  - Uses `easel.effects.stacking@1` (`resolveStacking(modifiers, policyMap)`).
  - Computes three simultaneous AC totals and breakdowns:
    - **`normal`**: All valid stacked modifiers (with positive `dex` capped by `maxDex`; if `loseDexToAC` is true, positive `dex` and `dodge` modifiers are excluded).
    - **`touch`**: Excludes modifiers of types `armor`, `shield`, and `natural` (plus `armorEnhancement`, `shieldEnhancement`, `naturalEnhancement`).
    - **`flatFooted`**: Excludes positive `dex` modifiers and `dodge` modifiers (retaining negative `dex` penalties).
  - Returns `{ normal, touch, flatFooted, breakdowns: { normal, touch, flatFooted } }`.
- `resolveSavingThrows({ saves, modifiers, policyMap })`:
  - Computes totals and breakdowns for each save key (`fort`, `ref`, `will` or custom save keys).

### 4.4 `easel.d20.health@1` (`server/health.mjs`)
- `resolveHealthState({ hp, maxHp, tempHp = 0, nonlethal = 0, deathThreshold = -10, disabledAtZero = true, staggeredOnNonlethal = true })`:
  - Pure function returning `{ hp, maxHp, tempHp, nonlethal, effectiveHp, status: "healthy" | "staggered" | "disabled" | "dying" | "dead" }`.
- `applyDamageToPools({ hp, maxHp, tempHp = 0, nonlethal = 0, lethalDamage = 0, nonlethalDamage = 0, healing = 0, tempHealing = 0 })`:
  - Temp HP does not stack (takes `Math.max(tempHp, tempHealing)`).
  - Lethal damage absorbs from `tempHp` first, then reduces `hp`.
  - Healing increases `hp` (capped at `maxHp`) and simultaneously reduces `nonlethal` by the same amount (standard 3.5e/PF1e rule).
  - Returns the new pool values without mutating database records directly.

### 4.5 `easel.d20.spellbook@1` (`server/spellbook.mjs`)
- `bonusSlotsForAbility(abilityModifier, maxSpellLevel = 9)`:
  - Returns an array of bonus slots for levels `1..maxSpellLevel` using `abilityModifier >= level ? Math.floor((abilityModifier - level + 4) / 4) : 0` (Level 0 gets `0` bonus slots).
- `resolveSpellDC({ base = 10, spellLevel, abilityModifier, modifiers = [], policyMap })`:
  - Computes `base + spellLevel + abilityModifier + stackedModifiers`.
- `rollConcentration({ casterLevel, abilityModifier, modifiers = [], dc = null })`:
  - Delegates to `easel.d20.check@1` with `casterLevel + abilityModifier + modifiers`.
- `rollCasterLevelCheck({ casterLevel, modifiers = [], targetSR = null })`:
  - Delegates to `easel.d20.check@1` against `targetSR`.

### 4.6 `easel.d20.size@1` (`server/size.mjs`)
- Exports the canonical 9-step size table (`fine` = 0 through `colossal` = 8) with:
  - `acAttackMod`: `[+8, +4, +2, +1, 0, -1, -2, -4, -8]`
  - `specialMod` (CMB/CMD/grapple): `[-8, -4, -2, -1, 0, +1, +2, +4, +8]`
  - `flyMod`: `[+8, +6, +4, +2, 0, -2, -4, -6, -8]`
  - `stealthMod`: `[+16, +12, +8, +4, 0, -4, -8, -12, -16]`
  - `spaceFeet`: `[0.5, 1, 2.5, 5, 5, 10, 15, 20, 30]`
  - `naturalReachTallFeet` & `naturalReachLongFeet`
- `stepWeaponDamageDice(diceFormula, steps)`:
  - Steps a weapon damage dice string (e.g. `"1d8"`, `"2d6"`) up or down `steps` size categories using the official 3.5e/PF1e FAQ progression chart (`1d2 → 1d3 → 1d4 → 1d6 → 1d8 → 2d6 → 3d6 → 4d6 → 6d6 → 8d6 → 12d6`).

### 4.7 `easel.d20.damagetypes@1` (`server/damagetypes.mjs`)
- `resolveDamageInstances({ instances, dr = [], resistances = {}, immunities = [], vulnerabilities = [], hardness = 0 })`:
  - Takes an array of damage instances `[{ amount, types: ["slashing", "magic"], isPrecision: false, isNonlethal: false }]`.
  - Applies immunities (`0`), vulnerabilities (`Math.floor(amount * 1.5)`), energy resistances (per energy type), object `hardness`, and Damage Reduction (`dr: [{ amount: 5, bypass: ["coldIron", "good"] }]`, applied once to the highest physical damage instance that does not match the bypass expression).
  - Returns `{ totalLethal, totalNonlethal, breakdownPerInstance }`.

### 4.8 `easel.d20.grid@1` (`server/grid.mjs`)
- `measureDistance5105(points, feetPerSquare = 5)`:
  - Implements alternating `5-10-5` diagonal grid movement where odd diagonals cost `5 ft` (1 square) and even diagonals cost `10 ft` (2 squares).
- `getThreatenedSquares({ originX, originY, spaceFeet, reachFeet, isReachWeapon = false })`:
  - Computes threatened grid squares, including the 3.5e/PF1e reach weapon donut rule (adjacent squares are not threatened by a standard reach weapon).
- `rasterizeTemplate({ shape, origin, direction, radiusFeet, feetPerSquare = 5 })`:
  - Computes the exact set of grid squares affected by a 3.5e/PF1e `burst`, `emanation`, `cone` (orthogonal vs diagonal 15/30/60-ft templates), or `line`.

### 4.9 `easel.d20.currency@1` (`server/currency.mjs`)
- `toCopper({ pp = 0, gp = 0, sp = 0, cp = 0 })`: returns total value in `cp`.
- `coinWeightLbs({ pp = 0, gp = 0, sp = 0, cp = 0 }, coinsPerLb = 50)`: returns `(pp + gp + sp + cp) / coinsPerLb`.
- `deductCurrency(wallet, cost, allowHigherDenominationChange = true)`: pure wallet arithmetic returning `{ ok, newWallet, changeGiven }`.

### 4.10 Client UI Widgets (`client/*.mjs`)
All client bricks in `easel.d20.kit` must use `easel.ui.elements@1` and `easel.ui.styles@1`:
- **`easel.d20.abilityblock@1`**: Renders the 6 ability rows/cards showing Base, Total, Modifier, Temp/Damage/Drain badges, and a clickable roll button per ability.
- **`easel.d20.defensebanner@1`**: Renders Normal AC, Touch AC, Flat-Footed AC, CMD/Special Defense, and Fortitude/Reflex/Will saves with hover modifier breakdown tooltips (`easel.rules.modifierlist@1`) and click-to-roll save buttons.
- **`easel.d20.vitality@1`**: Renders HP bar, Temp HP, Nonlethal damage bar, Wounds/Vigor toggle (optional), and fast `+Damage` / `+Heal` input controls.
- **`easel.d20.spellbook@1`**: Renders spell level tabs (`0`–`9`), prepared slots / spontaneous casts remaining per level, Domain/School slot indicators, Concentration & Caster Level roll buttons, and Cast buttons.
- **`easel.d20.attackcard@1`**: Renders a rich chat/sheet attack card displaying primary/iterative attack rolls, critical threat & confirmation badge, damage instance breakdown by damage type, saving throw DC button, and GM "Apply Damage (Full / Half / Negate)" action buttons.
- **`easel.d20.rolldialog@1`**: Pre-roll modal allowing the player/GM to toggle conditional modifiers (Power Attack, Deadly Aim, Flanking, Haste, Cover, Point-Blank Shot), situational bonus input, Take 10 / Take 20, and Roll Mode (Public, GM-Only, Blind, Self) before dispatching the server action.
- **`easel.d20.equipmentslots@1`**: Paper-doll / slot list widget for standard d20 magic item body slots (`head`, `headband`, `eyes`, `shoulders`, `neck`, `chest`, `body`, `armor`, `belt`, `wrists`, `hands`, `ring1`, `ring2`, `feet`, `shield`, `mainHand`, `offHand`, `slotless`).

## 5. Anti-Spaghetti Guardrails for Section 04
1. **No PF1e-Exclusive Hardcoding**:
   - Do **not** hardcode Pathfinder 1e's exact 35 skill names or PF1e class progressions inside `easel.d20.kit`. Keep `easel.d20.kit` reusable for any d20 ruleset (3.5e, PF1e, PF2e, 5e, Starfinder).
2. **No Record Schemas or Database Queries**:
   - `easel.d20.kit` is a **Kit** (`type: "kit"`). Every server brick must be a pure calculation helper accepting plain objects/arrays and returning plain objects/arrays. Never call `context.query` or mutate database records directly inside `easel.d20.kit`.
3. **Always Delegate Stacking & RNG to Core Kits**:
   - Never call `Math.random()` inside `easel.d20.check@1`—always load and use `easel.dice.roller@1`.
   - Never write a duplicate bonus-stacking loop inside `easel.d20.defense@1` or `easel.d20.abilities@1`—always pass modifiers and the caller's `policyMap` to `easel.effects.stacking@1`.
4. **Stay at `@1` & Zero Comments**:
   - All interfaces are registered at `version: 1`. Follow `Easel/AGENTS.md` (zero code comments).
